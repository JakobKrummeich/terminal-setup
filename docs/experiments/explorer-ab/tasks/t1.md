The tool keeps one persisted record per review session under its state directory, and today nothing but a manual `rm` ever removes one; ended sessions accumulate forever.

Add a first-class way for a user to list every stored session (including ones already closed, which the default view hides) and to delete sessions that are closed or older than a given cutoff, with a dry-run mode that prints exactly what would be deleted and changes nothing. Deleting must refuse to touch a session that is still active unless explicitly forced, and must report a count of what it removed. Follow the existing output conventions of this CLI (structured output, contextual next-step hints, error codes, exit codes).

Acceptance criteria:
- The existing test suite still passes (`npm test`, 1112 tests).
- New tests cover selection, dry-run, and the refusal to delete active sessions.
- The change fits the conventions already used in this codebase.
