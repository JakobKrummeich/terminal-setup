The facilitator must be able to drive the quiz phase step by step: reveal the correct answer for the current question, show that question's learning text, and move on to the next question.

Model the rules in the domain: the quiz starts before the first question, an answer can only be revealed once a question is active, learning text only after the reveal, and moving on is only allowed once the learning text was shown; moving on resets reveal and learning-text state. Expose these as facilitator intents over the same real-time control path the existing phase advancement uses, rejected with the existing rejection codes when the caller is not the facilitator, the session is unknown, or the workshop is not in the quiz phase.

Acceptance criteria:
- Follow the conventions already used in this codebase.
- Add unit tests for the new domain rules and for the intent handling.
- The existing test suites still pass.
